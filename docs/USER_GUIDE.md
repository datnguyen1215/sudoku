# Sudoku - User Guide

## Welcome to Mobile-First Sudoku! 🎯

A modern, accessible, and lightning-fast Sudoku experience designed for mobile devices and optimized for all platforms.

## Getting Started

### Installation (PWA)
1. **On Mobile**: Tap "Add to Home Screen" when prompted
2. **On Desktop**: Click install icon in address bar
3. **Offline Play**: Works completely offline once installed

### Game Interface

#### Main Game Screen
- **Sudoku Grid**: 9x9 grid with 3x3 sub-grids
- **Number Pad**: Touch-friendly number input (1-9)
- **Control Buttons**: New Game, Hint, Undo, Clear
- **Game Info**: Timer, difficulty level, progress

#### Visual Elements
- **Selected Cell**: Blue highlight
- **Original Numbers**: Gray background (unchangeable)
- **Error Numbers**: Red highlight with error indication
- **Notes**: Small numbers in corner for possibilities

## How to Play

### Basic Rules
1. **Fill the Grid**: Each row, column, and 3x3 box must contain digits 1-9
2. **No Repeats**: Each digit appears exactly once in each row, column, and box
3. **Use Logic**: No guessing required - every puzzle has a unique solution

### Game Controls

#### Cell Selection
- **Touch/Click**: Tap any cell to select it
- **Keyboard**: Use arrow keys to navigate between cells
- **Visual Feedback**: Selected cell highlighted in blue

#### Number Input
- **Number Pad**: Tap numbers 1-9 to fill selected cell
- **Keyboard**: Press number keys 1-9 directly
- **Clear**: Use Clear button or Delete/Backspace key

#### Advanced Features
- **Notes Mode**: Toggle to add small possibility numbers
- **Undo**: Reverse your last move
- **Hint**: Get help with next logical move
- **Auto-Save**: Game progress saved automatically

## Tips & Strategies

### Beginner Tips
1. **Start with Easy**: Build confidence with easier puzzles
2. **Look for Singles**: Find cells with only one possible number
3. **Use Process of Elimination**: Cross out impossible numbers
4. **Check Rows/Columns**: Look for missing numbers in each line

### Intermediate Strategies
1. **Hidden Singles**: Find numbers that can only go in one place
2. **Naked Pairs**: Two cells with same two possibilities
3. **Box/Line Reduction**: Use box-row/column interactions
4. **Use Notes**: Track possibilities to see patterns

### Advanced Techniques
1. **X-Wing**: Advanced elimination pattern
2. **Coloring**: Track chains of connected cells
3. **Forcing Chains**: Multi-step logical deduction
4. **Trial and Error**: Last resort for extremely hard puzzles

## Troubleshooting

### Common Issues

#### Game Won't Load
- **Check Internet**: Initial load requires connection
- **Clear Cache**: Refresh browser or restart app
- **Update Browser**: Ensure modern browser version

#### Touch Not Working
- **Restart App**: Close and reopen application
- **Check Zoom**: Ensure page not zoomed incorrectly
- **Device Restart**: Restart your mobile device

#### Performance Issues
- **Close Other Apps**: Free up memory on mobile
- **Update Browser**: Use latest browser version
- **Clear Storage**: Clear browser cache and data

#### Save Game Lost
- **Browser Storage**: Check if browser storage disabled
- **Private Mode**: Private/incognito mode doesn't save
- **Storage Full**: Clear other website data
