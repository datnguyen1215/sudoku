← How to Play

Objective

Fill the 9x9 grid with numbers 1-9 so that each row, column, and 3x3 box contains all digits from 1 to 9.

The Grid

The grid is divided into 9 boxes, each containing 9 cells.

Rules

• Each row must contain 1-9
• Each column must contain 1-9
• Each 3x3 box must contain 1-9
• No duplicates allowed!

Tips

• Start with rows, columns, or boxes that have many given numbers
• Use the Notes feature to track possibilities
• Look for singles and pairs
